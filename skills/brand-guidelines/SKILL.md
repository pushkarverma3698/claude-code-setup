# Brand Guidelines Skill

Use this skill to lock in a brand identity so all future outputs sound and look exactly like the specific brand.

## Instructions
1. **Identify Brand Assets**: Ask the user to provide or confirm their brand guidelines document (voice, tone, color hex codes, typography, logo usage).
2. **Apply Tone of Voice**: For all written copy (emails, posts, articles), strictly adhere to the defined tone (e.g., professional, witty, casual, authoritative).
3. **Apply Visual Rules**: For any design or code outputs (CSS, Tailwind, HTML), exclusively use the brand's approved color palette, fonts, and spacing rules.
4. **Consistency Check**: Before outputting the final result, perform a check against the core brand rules to ensure complete alignment. Do not use generic placeholders if brand assets are available.

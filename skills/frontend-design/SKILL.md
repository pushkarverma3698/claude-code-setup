# Front-End Design Skill

This skill guarantees that all generated UI code looks premium, modern, and production-ready.

## Instructions
1. **Avoid Basic Layouts**: Never output simple, unstyled HTML. Avoid basic "AI slop".
2. **Premium Design Aesthetics**:
   - Use vibrant, tailored color palettes (e.g., sleek dark modes or harmonious HSL colors).
   - Implement modern typography (Inter, Roboto, Outfit).
   - Use glassmorphism, smooth gradients, and subtle shadows for depth.
   - Include micro-animations for hover states and transitions to make the UI feel alive.
3. **Structured Design System**: Apply consistent design tokens for spacing, padding, margins, and border-radii. 
4. **Code Generation**: Output complete, responsive HTML/CSS or React/Tailwind code that exactly matches the requested interface (dashboard, landing page, component).
5. **Production Ready**: Ensure the code is accessible, semantic, and structurally sound for immediate use in a production environment.

# The SEO Skill

Compress a traditional SEO audit into a single workflow. 

## Instructions
1. **Gather Inputs**: Identify the target URL and up to 3 competitor URLs provided by the user.
2. **Technical Audit**: Analyze the target URL for core SEO factors:
   - Title tags and meta descriptions (length, relevance)
   - Heading structure (H1, H2 hierarchy)
   - Semantic HTML and accessibility
   - Keyword density and targeting
   - Performance indicators (if available from source data)
3. **Competitor Comparison**: Compare the target site's structure and content strategy side-by-side with the competitors.
4. **Prioritize Fixes**: Output a ranked list of fixes. Prioritize actions that "move the needle the most" (e.g., fixing missing H1s over tweaking alt text).
5. **Actionable Recommendations**: For every issue, provide the exact code change or content rewrite needed to fix it.
